# Daily Life Toolkit

Nine free tools for everyday life, in one place — money, study, dates, photos and documents. No sign-up, no uploads: everything runs in your browser, on your own device.

**Use it online:** https://iammanojbhatta.github.io/iammanojbhatta/daily-life-toolkit/

## The tools
| Tool | What it does |
|---|---|
| Daily Expense Tracker | Income & expenses in rupees, with balance and monthly summary. |
| NEB GPA Calculator | Class 11/12 marks → grade and GPA on the official NEB scale. |
| Nepali Date Converter | BS ↔ AD date conversion, both ways, with Nepali month names. |
| Image Compressor | Shrink photos for forms and web — quality slider, live savings. |
| File Extension Changer | Real PNG ↔ JPG ↔ WebP conversion, plus a safe rename tool. |
| PDF to Word | Extract a PDF's text into an editable Word document. |
| Word to PDF | Turn a .docx document into a clean A4 PDF. |
| Password Generator | Strong random passwords, generated on your device only. |
| Daily To-Do Planner | Tasks with priorities, due dates and a progress bar. |

## Why one toolkit?
One link to bookmark, one link to share. Every tool is a single self-contained page — open it, use it, close it. Data tools (expense tracker, to-do) save only in your browser's local storage.

Made by [Manoj Bhatta](https://github.com/iammanojbhatta) — free for everyone.
